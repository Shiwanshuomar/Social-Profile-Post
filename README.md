# Social Profile & Post

A simple Express, EJS and MongoDB user profile CRUD project.

## Added small feature
- Live search users by name or email on the All Users page.
- Shows how many users match the current search.

Existing create, read, update and delete routes are kept unchanged.

## Run locally
1. Install Node.js and make sure MongoDB is running.
2. Open a terminal in this folder.
3. Run `npm install`.
4. Run `npm run application`.
5. Open `http://localhost:3000`.

If your MongoDB connection string is configured in `models/user.js`, make sure it matches your local setup.
